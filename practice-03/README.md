## 1. Цель работы

Цель практической работы — изучить работу с DOM, событиями браузера и повторной отрисовкой интерфейса.

В ходе работы реализован браузерный интерфейс управления списком задач на основе бизнес-логики из практической работы № 2.

В работе использованы:

- поиск элементов DOM;
- создание элементов через JavaScript;
- `textContent`;
- `dataset`;
- обработчики событий;
- делегирование событий;
- `event.target` и `event.currentTarget`;
- фильтрация задач;
- изменение и удаление задач;
- повторная отрисовка списка;
- отображение статистики;
- обработка пустого списка и пустого результата фильтра;
- сохранение клавиатурного фокуса после действий.
